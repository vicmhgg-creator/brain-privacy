# BRAIN privacy policy

Last updated: 2026-10-30

BRAIN is a personal tool used only by its owner. It is not available to anyone else.

## What it accesses
With the owner's explicit consent, BRAIN reads the owner's own Gmail, Google Calendar and Google
Drive data using read-only Google permissions (gmail.readonly, calendar.readonly, drive.readonly).
It never sends email, never edits or deletes anything, and never asks for write access.

## How the data is used and stored
Data is used only to let the owner search and ask questions about their own information. It is
stored encrypted, in the owner's own storage. It is not sold, not shared with third parties, not
used for advertising, and not used to train AI models. Content from third parties found in the
data is treated as data, never as instructions.

## Google API data
BRAIN's use and transfer of information received from Google APIs adheres to the Google API
Services User Data Policy, including the Limited Use requirements.

## Retention and deletion
The owner can delete stored data and revoke access at any time at
https://myaccount.google.com/permissions or by signing out inside the tool.
